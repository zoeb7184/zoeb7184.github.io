ML/AI

German Day-Ahead Electricity Price Forecaster

An end-to-end ML forecasting pipeline for German electricity prices, cutting forecast MAE by 62% over baseline using LightGBM.

Python LightGBM FastAPI Streamlit Docker SMARD API REST API
Live Demo → GitHub → ← Back to Projects

Overview

This project forecasts German day-ahead electricity prices — the prices set a day in advance on the German power exchange — using public market data published by SMARD, Germany's official electricity market data platform.

Problem

Day-ahead electricity prices in Germany are highly volatile, and can even go negative during periods of high renewable output. A naive forecasting baseline handles these swings badly, which is exactly when accurate forecasts matter most for planning.

Approach

8,664 rows of SMARD market data were pulled and engineered into time-series features capturing demand, generation mix, and calendar effects. A LightGBM model was trained against a baseline forecaster, then served through a FastAPI REST endpoint, containerized with Docker for reproducible deployment, with a Streamlit front-end for interactive exploration of forecasts.

Results

LightGBM reduced forecast MAE by 62% over the baseline, from €34.00/MWh down to €13.01/MWh. On the hardest subset — negative-price hours — MAE improved from €56.10/MWh to €19.43/MWh.

Challenges

Negative-price hours, common in the German market during high wind/solar output, badly skewed the baseline's error and needed to be evaluated as their own subset rather than averaged away inside an overall metric, which is what surfaced how much the model specifically improved on exactly the hours that matter most for real trading decisions.
