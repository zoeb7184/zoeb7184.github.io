Cardiovascular Disease Risk Prediction

An XGBoost classifier predicting cardiovascular disease risk on 308,854 CDC BRFSS health records, achieving AUC-ROC 0.836.

Python XGBoost Scikit-learn Pandas CDC BRFSS Classification
GitHub → ← Back to Projects

Overview

This project builds a binary classifier that predicts cardiovascular disease (CVD) risk from the CDC's Behavioral Risk Factor Surveillance System (BRFSS) — a large public health survey dataset.

Problem

Most people at risk of cardiovascular disease are, by definition, a minority of the surveyed population, so a classifier optimized for raw accuracy alone tends to just predict 'no CVD risk' for nearly everyone and still score deceptively well.

Approach

An XGBoost classifier was trained on 308,854 CDC BRFSS records, with explicit class-imbalance handling (weighting/resampling toward the minority at-risk class) rather than relying on accuracy alone. Feature selection narrowed the input space to the most predictive risk factors, and a post-hoc interpretability analysis was run to understand which features were actually driving individual predictions.

Results

The final model achieved an AUC-ROC of 0.836 on held-out data — a threshold-independent measure that reflects genuinely useful risk ranking, not just accuracy inflated by class imbalance.

Challenges

The central challenge was the class imbalance itself: without deliberate handling, the model gravitates toward ignoring the at-risk minority class entirely. Getting feature selection right — keeping the model interpretable to a non-technical health audience without sacrificing predictive power — required iterating between model performance and explainability rather than optimizing purely for the metric.
