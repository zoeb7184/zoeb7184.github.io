Quora Duplicate Question Detection

A progressive feature-engineering pipeline improving duplicate-question detection accuracy from 72.0% to 76.3% on 404,290 Quora pairs.

Python Scikit-learn XGBoost NLP fuzzywuzzy Feature Engineering
GitHub → ← Back to Projects

Overview

This project tackles the classic Quora Question Pairs problem: given two questions, determine whether they are asking the same thing, even when worded completely differently.

Problem

A simple bag-of-words model can only catch duplicates that share vocabulary — it misses semantically identical questions phrased with different words, synonyms, or reordered structure, which is precisely where most real duplicate pairs live.

Approach

Starting from a BOW baseline over 404,290 question pairs, the pipeline progressively added 15+ token-level and fuzzy string-matching features using the fuzzywuzzy library — things like token overlap ratios, longest common substring, and edit-distance-based similarity — that a plain bag-of-words representation can't express. Three classifiers were then benchmarked on top of the enriched feature set: Logistic Regression, Random Forest, and XGBoost.

Results

Accuracy improved by 6.1% over the BOW baseline (72.0% → 76.3%), and F1-score improved by 29% (0.519 → 0.671) — a much larger relative jump, reflecting that the added features specifically helped catch duplicates the baseline was missing, not just overall label distribution.

Challenges

Fuzzy string matching is computationally expensive per-pair, and at 404,290 pairs a naive implementation would have been impractically slow — this required batching and vectorizing the fuzzy-matching computation to keep feature extraction and training tractable at that scale.
